# 📶 WiFiVision

<p align="center">
  <strong>A Modern Progressive Web App (PWA) & Desktop Application for Wi-Fi Network Analysis and Visualization.</strong>
</p>

<p align="center">
  Monitor Wi-Fi networks, visualize signal propagation, detect motion, and explore network performance through an intuitive and responsive interface.
</p>

**🔗 https://wifivision.netlify.app/**

# ✨ Features

- 📡 Real-time Wi-Fi network visualization
- 📊 Interactive network monitoring
- 📶 Live signal propagation display
- 🚶 Motion detection support
- ⚡ Progressive Web App (PWA)
- 🖥️ Electron Desktop Application
- 📱 Responsive UI

# 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/vedhant-khajuria/WiFiVision.git
```

### Move into the project folder

```bash
cd WiFiVision
```

### Install dependencies

```bash
npm install
```

---

# ▶️ Run the Project

Open **Windows PowerShell** or **Command Prompt (CMD)** inside the project folder and run:

```bash
npm.cmd start
```

The application will launch automatically.
